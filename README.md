# 现代两居 · 3D 看房

一个单文件、可交互的 3D 看房网页（Three.js + 原生 JS），支持桌面与手机。

## 在线预览

https://sus990609-cpu.github.io/3d-house-tour/

## 功能

- 轨道视角：拖拽旋转、滚轮 / 双指缩放
- 房间快速跳转：客厅 / 餐厅 / 厨房 / 主卧 / 次卧 / 卫生间
- 第一人称漫游：WASD + 鼠标（手机：方向键 + 右侧拖动）
- 家具热点、昼夜切换、小地图
- 单文件 index.html，Three.js 已内联，可离线打开

## 技术

- Three.js r128（内联）
- 原生 JavaScript、HTML、CSS
- AI 协作：ChatGPT / Claude 生成场景与交互代码，DeepSeek 做代码审查，即梦生成参考图
